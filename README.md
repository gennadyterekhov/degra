# degra

`degra` читает JSON от `ast-go`, `ast-js`, `ast-php` или `ast-py` из stdin и печатает в stdout зависимости между файлами из этого JSON.

```sh
go build -o degra ./cmd
./degra --lang go --go-module github.com/gennadyterekhov/import-layers-go < examples/ast-go-no-vendor.json
./degra --lang js < examples/ast-js-no-vendor.json
./degra --lang php < examples/ast-php-no-vendor.json
./degra --lang py < examples/ast-py-no-vendor.json
```

Для дерева одного файла укажите его относительный путь через `--file-name`. Для дерева каталога CLI берёт пути из ключей входного объекта.

По умолчанию каждый ключ — путь к файлу, а его значение — отсортированный список файлов, которые он импортирует. Ключи появляются только для файлов с найденными зависимостями. Если связей нет, результат — `{}`.

```json
{"src/main.ts":["src/lib.ts"]}
```

С флагом `--graph-edges` CLI выводит массив связей, отсортированный по `from`, затем по `to`. Если связей нет, результат — `[]`.

```json
[{"from":"src/main.ts","to":"src/lib.ts"}]
```

В обоих форматах связи уникальны. Ошибки идут в stderr, код завершения — `2`.

- **Go.** Передайте объявленный в `go.mod` путь модуля через `--go-module`, чтобы сопоставить импорты модуля с каталогами. Относительные и vendored-импорты разрешаются по путям из входа. В AST отсутствуют настройки сборки и замены модулей.
- **JS/TS.** Поддерживаются импорты, реэкспорты, `require`, `import()` и импорты типов со строковым путём. Цели ищутся среди предоставленных файлов по относительному пути или в `node_modules`. Для алиасов TS и полей `exports` и `main` пакетов нужны данные, которых в AST нет.
- **PHP.** Директивы `use` сопоставляются с объявленными классами, функциями и константами. Статические `include` и `require` разрешаются по относительным путям и выражениям с `__DIR__` или `__FILE__`.
- **Python.** Поддерживаются абсолютные и относительные импорты, включая проекты с каталогом `src`, и распознаваемые вызовы динамического импорта со строковым именем модуля.

## Кто импортирует файл

`degra reverse` принимает JSON-граф в любом из двух форматов `degra`. По умолчанию команда выводит объект, где ключ — импортируемый файл, а значение — отсортированный список файлов, которые импортируют его напрямую.

```sh
go run ./cmd reverse < examples/output/imports-php.json > importers.json
```

Например, из `{"main.php":["lib.php"]}` получится `{"lib.php":["main.php"],"main.php":[]}`. В результате остаются все файлы из входного графа, включая явно заданные изолированные узлы. Команда обращает каждое прямое ребро. Циклы и петли хранятся как обычные ссылки между ключами.

## Визуализация всего графа

Для интерактивного просмотра создайте HTML из каталога `degra`:

```sh
go run ./cmd reverse --format html < examples/er/output/ast-php-er-imports.json > examples/er/output/importers.html
```

Откройте `importers.html` в браузере. Граф встроен в файл и работает без сети. В общем виде файлы сгруппированы по папкам первого уровня. Число на стрелке между папками показывает количество прямых файловых связей в этом направлении. Нажмите на папку, чтобы увидеть файлы и связи внутри неё, и на её заголовок, чтобы свернуть.

Выберите раскрытый файл или найдите его по имени либо части пути. В режиме импортёров выбранный файл находится слева, прямые импортёры выделены зелёным в следующей колонке, а остальные разложены по кратчайшему числу шагов и выделены оранжевым. Порядок узлов в колонках подбирается по соседним связям, чтобы сократить пересечения. Связи внутри колонки и связи, ведущие назад, показаны пунктиром. Колесо мыши меняет масштаб, перетаскивание перемещает граф, а кнопка «Весь граф» возвращает обзор с ранее раскрытыми папками.

### Экспорт в SVG через Graphviz

Установите [Graphviz](https://graphviz.org/download/). Из каталога `degra` выполните:

```sh
go run ./cmd reverse --format dot < examples/er/output/ast-php-er-imports.json > examples/er/output/er-importers.dot

sfdp -Goverlap=prism -Gsplines=line -Tsvg examples/er/output/er-importers.dot -o examples/er/output/er-importers.svg
```

Откройте SVG в браузере. По умолчанию вершины подписаны полными путями и окрашены по первому сегменту пути. Стрелка идёт от импортируемого файла к импортирующему. Раскладка `sfdp` рассчитана на большие графы. [Документация Graphviz sfdp](https://graphviz.org/docs/layouts/sfdp/)

Для компактного обзора добавьте `--no-labels`. Полные пути останутся во всплывающих подсказках.

```sh
go run ./cmd reverse --format dot --no-labels < examples/er/output/imports-php.json > importers-compact.dot
sfdp -Goverlap=prism -Gsplines=line -Tsvg importers-compact.dot -o importers-compact.svg
```

Для иерархической раскладки слева направо можно использовать тот же DOT:

```sh
dot -Grankdir=LR -Tsvg examples/er/output/er-importers.dot -o examples/er/output/importers-layered.svg
```

Для интерактивной работы с узлами и фильтрами откройте `er-importers.dot` в Gephi как ориентированный граф. [Документация импорта DOT в Gephi](https://docs.gephi.org/desktop/User_Manual/Import/GraphViz_DOT_Format/)

Тесты запускаются командой `go test ./...`.
